# Stream S (surfaces): notes for the v2010 cross-bet fix build

## How to apply
- Patch: `python3 qa/cross_v2009/fix/S_patch.py <file.html> [--i18n <i18n dir>]`.
  - It has 22 edits.
  - Every anchor is asserted unique before anything is written, and checked again while applying.
- It applies cleanly to all of these:
  - `BASE_v2009.html`
  - pristine v2008 `golf-app.html`
  - `www/index.html`
  - BASE + E + U, in the order E, U, S. This result is byte-identical to `work_S.html`.
- Working copy: `fix/work_S.html` = BASE_v2009 + E + U + S.
- BGVER / BG_BUILD were not touched. Nothing was pushed, and nothing was written to the database.

**Source layout**
- `S_patch.py` is generated by `S_patch_src.py` from:
  - `S_js_helpers.js`
  - `S_js_gps.js`
  - `S_js_models.js`
  - `S_i18n.json`
  - `S_patch_tpl.py`
- Edit those files and re-run `python3 S_patch_src.py`.

**i18n**
- `--i18n i18n` adds 23 es/ko/ja/zh entries: 9 strings and 14 patterns. It is idempotent and never overwrites an existing key.
- `fix/i18n_S/` is the repo `i18n/` with S's entries merged. It does not include U's; at assembly, run U's and S's `--i18n` on the real directory.
- The entries cover S's new strings and E's engine status texts as S renders them through `bgT`:
  - "{0} left early — forfeit"
  - "waiting on a blank hole"
  - "dormie"
  - all six dropped-row texts ("… is not on any card — bet dropped", nine-twice, no hole in common, no shared hole scored, waiting for the cart / never started)
  - the conflict line
- The glossary's de-gambled wording is followed: no apuesta/베팅/賭け/赌 words.

## Read-only rule
Every surface reads `t2ComputeCrossGroupMatches` (E's contract shape) and settles nothing.

`_t2CrossNorm` makes every field safe to read. It derives `statusShort`, `pending`, `keys`, `netByKey` and so on from the old v2008 shape. When a field is missing, the output is garbage, or the engine throws, the surface degrades instead of throwing. test_S part A covers all of these, and passes 48/48 on BASE + S with the old v2008 engine.

## Leftovers / needs from other streams
- **Assembly:** run `S_patch.py <html> --i18n i18n` after E's and U's patches, then re-run `test_S.js` on the result.
- **U's i18n uses "apuesta"** in its Spanish texts (for example "elige a alguien de tu grupo para esta apuesta", "no hay apuesta entre grupos"). The glossary (rule 3) forbids apuesta/apostar and 내기 / 賭け / 下注 for App Store review. Its ko/ja/zh also use 내기 / 賭け / 下注. That needs a re-word before shipping; it is U's text, so I left it alone.
- **Scorecard image (share PNG, `_mvModel` ~61347):** the canvas draws one row per player and ignores `_multi`. A player who is only in cross bets gets their first cross line there; a player in several gets the stacked cell. This was not changed: the share-image painter is not S's function.
- **Stored-record fallback** reads `tournament_matches` through `t2GetMatches`, once a minute per event, and only after Q's SQL is run. Before that the table has no `cross_key` rows, so nothing shows.
- The legacy `_t2NetArray` is now unused by S, but other code may call it, so it was left in place.
