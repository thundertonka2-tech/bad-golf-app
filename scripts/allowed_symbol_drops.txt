# Bad Golf — DECLARED SYMBOL REMOVALS
#
# The stale-base guard (scripts/guard_stale_base.sh, check 1) blocks a commit that
# drops a top-level function or const the previous build had, because that is the
# fingerprint of writing from a STALE COPY of golf-app.html — the failure that
# silently deleted the whole TEMP-handicap feature between V842 and V843.
#
# A removal you actually meant to make goes here, one symbol per line. The guard
# still PRINTS every allowed removal so it can never happen quietly, and every
# other check (truncation, web/iOS drift, big shrink, version-going-backwards)
# stays fully armed. This is the right way to confirm a deletion — NOT
# `git commit --no-verify`, which turns the entire guard off.
#
# Housekeeping: once a removal has shipped, its entry can be deleted from this
# file — the guard only ever compares the working tree against HEAD, so a symbol
# that is gone from both no longer needs declaring.
